# Stacey D. Ballares — Portfolio

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` directly in a browser, or serve the folder with VS Code Live Server.

## Deploy

Upload the complete folder to Vercel, Netlify, GitHub Pages, or any static hosting service. No build command or package installation is required.

## Main files

- `index.html` — portfolio content and sections
- `styles.css` — primary layout and theme
- `hover.css` — project-card hover interactions
- `carousel.css` — coverflow-style project gallery with previous/next navigation
- `contact.css` — contact cards and direct Gmail compose button
- `id-size.css` — responsive sizing for the interactive ID card
- `lanyard.css` — animated and draggable ID lace
- `theme.css` — remembered light and dark modes
- `script.js` — navigation, theme switching, scroll reveals, cursor glow, and ID dragging
- `assets/` — project screenshots and the ID-card portrait
